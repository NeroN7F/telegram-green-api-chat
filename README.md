# Telegram Chat

Простой чат на React для отправки и получения текстовых сообщений в Telegram через GREEN-API.

## Запуск

Нужны Node.js 24 и npm.

```bash
npm ci
npm run dev
```

Откройте адрес из терминала. Обычно это [http://localhost:5173](http://localhost:5173).

## Подключение

1. Создайте инстанс Telegram в [GREEN-API](https://console.green-api.com/) и авторизуйте его.
2. В настройках инстанса включите входящие уведомления и очистите поле Webhook URL.
3. Введите в приложении ID инстанса, API-токен и адрес сервера API из личного кабинета.
4. Нажмите «Подключиться».

Для статусов доставки включите уведомления об исходящих сообщениях и их статусах в GREEN-API.

## Как пользоваться

Нажмите «Новый чат» и введите международный номер телефона или `@username` собеседника.

Напишите сообщение и нажмите Enter. Для новой строки используйте Shift + Enter. Ответ собеседника появится в чате автоматически.

Поддерживаются только текстовые сообщения до 4 096 символов. Токен и переписка хранятся в памяти вкладки. Обновление страницы или выход очищают их.
